## Placeholders currently in use
All 3D content (map greybox, zombies, weapons, effects) is built from Godot primitive meshes merged at runtime, plus the generated textures and sounds above.
Integration points: `client/data/visuals.json` (`model` paths), `client/assets/sfx/` (same file names), the map scene (replace greybox meshes, keep node groups).
These are technical stand-ins with documented integration points, **not** finished art.

## Fetching from this environment
The cloud build environment can reach only GitHub and package registries. Kenney, Poly Haven, Quaternius, OpenGameArt, ambientCG and itch.io are blocked, so CC0 packs must be uploaded by the owner to `assets/incoming/`.

## Incoming
Files dropped by the owner into `assets/incoming/` are reviewed, licence-checked, recorded here, then moved into `client/assets/`.
