# Art pipeline (procedural, in-repo)

All 3D art is generated by Python scripts running Blender as a module (`bpy`), so every asset is original, reproducible and free of licence issues.

## Setup (cloud session)
```bash
python3 -m venv /opt/blender-venv && /opt/blender-venv/bin/pip install bpy==4.5.14   # Blender 4.5 LTS
```

## Build
```bash
/opt/blender-venv/bin/python art/blender/build_zombies.py --preview /tmp/art   # zombie_walker.glb, zombie_runner.glb
/opt/blender-venv/bin/python art/blender/build_props.py --preview /tmp/art     # supply_box.glb
```
Outputs go to `client/assets/models/`. They are committed, and CI does not rebuild art. `--preview` renders Cycles stills for review.

## How it works
| Step | Tool |
|---|---|
| Anatomy | skin modifier over a joint graph (muscle joints, clawed fingers, boots) + subdivision; head from a sculpted sphere (brow, sockets, nose, open jaw, ears) |
| Clothing and props | extra meshes (cap, belt, coat skirt), boxes and cylinders for the crate |
| Rig | 23-bone humanoid, auto weights; rigid parts (cap, eyes, belt, coat) get explicit weights |
| Animation | keyframed in code. Arms use direction "aims"; feet stay planted automatically (`plant()`). Actions: idle, walk, run, attack (strike at 13/30 s), hit, death |
| Textures | `painter.py` rasterises the UV layout, recovers each texel's 3D rest position and paints with numpy: skin rot, veins, bruises, eye sockets, teeth, blood soak and drips, torn clothing with ragged edges, insignia. A Cycles AO bake is multiplied in. 1024² for zombies, 512² for the crate |
| Export | GLB, JPEG textures, one primitive per material, emissive eyes and glow kept as separate materials |

## Budgets
- Zombie: about 9–11k triangles, 1 texture, 2 materials. Godot generates LODs at import.
- Supply box: about 3k triangles, 2 small textures.

## Game integration
- `client/data/visuals.json` → `zombies.<id>.model`, `locomotion`, `locoSpeed` (playback speed follows real movement speed).
- `ZombieView` plays idle, locomotion, attack (time-scaled so the swing lands when the sim applies damage), hit and death.
- `BoxView` opens the node named `Lid` and lights `GlowAnchor`.
- Review in game: `?showcase=1` (zombies up close), `?showcase=box` (opens the supply cache).
